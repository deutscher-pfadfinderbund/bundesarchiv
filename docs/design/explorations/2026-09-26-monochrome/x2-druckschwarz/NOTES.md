# X2 Druckschwarz
Thesis: a printed register in pure black ink on white. A solid black masthead, heavy letterhead rules opening every division, oversized serif counts as folios. No fill between black and white.
Primary theme: light (it shows the idea best). Dark is the exact inversion, except the masthead stays black and a white heavy rule closes it (a white slab on top of a dark page would glare).
| token | light | dark |
|---|---|---|
| ground / ink / ink-2 (text only) | #fff / #000 / #595959 | #000 / #fff / #a6a6a6 |
| rule (hairline; heavy = ink, 6px) / fill-inverse | #c4c4c4 / #000 | #4a4a4a / #fff |
| error / login gray (door only) | #c4000b / #333 | #ff6b61 / #3d3d3d |
Judge: (1) Start page as stacked bands, each with a big count as folio (9 · 2.506 · 5); the Zeitleiste is a black bar chart, and "Unbekannt" (347) is an outlined bar. (2) The masthead: black in both themes, closed by a white rule in dark only. (3) Entwurf = dashed-outline mono mark; future compartments = dashed heavy rule, gray heading, "später · Idee" mark.
