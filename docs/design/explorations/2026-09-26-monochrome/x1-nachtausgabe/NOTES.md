# X1 Nachtausgabe
Thesis: a night edition of a newspaper: near-black ground, heavy sans display type at large scale, a section grid of hairline rules, and inversion as the only emphasis.
Primary theme: dark. Light is the same system on white with black ink.
| token | dark | light |
| --- | --- | --- |
| ground / ink / ink-2 | #0c0c0c / #f7f7f7 / #a2a6ad | #ffffff / #0a0a0a / #5a5e64 |
| rule / fill-inverse / error | rgba(255,255,255,.17) / #f7f7f7 / #ff6259 | rgba(0,0,0,.14) / #0a0a0a / #c4170f |
Judge: (1) Scale contrast: 5–6rem page titles and 2–3rem numerals next to 1rem working text. Is it confident or loud?
(2) Inversion as the one emphasis device: active nav, primary buttons, current row, current page. Entwurf is a dashed mono mark plus italic title, no color.
(3) Start page as a front page: Bestände ledger | Zuletzt, a full-width decade strip with ink bars ("Unbekannt" set off by a heavy rule), and future compartments marked with gray headings and dashed rules.
