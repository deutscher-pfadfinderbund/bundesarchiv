{% comment %} Ledger organism — the results register. A dense, aligned alternative to the card list. Params: - rows — list of dicts, each carrying a ledger_row's params (title, href, ref_code, datierung, typ, draft, visibility, action_label, action_href) - sort_links — list of {label, key, query, active, order} for the sortable column headers; each header is a plain link (URL-as-state, no JS). order "asc"|"desc" marks direction. - narrow (bool) — density mode: full (aligned columns, default) vs narrow (two-line compact rows, the mail-client fold: line 1 = SIG + Titel, line 2 = Datierung · Typ). The class swap is the ONLY difference — same rows, CSS reflows the grid. Every column head — sortable or not — uses the ONE label type role (small-caps, letterspaced, on-surface-variant), identical size/case/weight/color. The only systematic modifiers on that base: sortable heads get the link affordance (ink + underline on HOVER, stamp-grammar link rule); the active sort column gets exactly one direction glyph (▲/▼), never a different font treatment. Body marks (SIG codes, Datierung) carry ink per the stamp grammar; everything else is neutral chrome. {% endcomment %}
